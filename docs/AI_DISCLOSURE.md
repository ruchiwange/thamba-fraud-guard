# AI disclosure

The competition guidelines require teams to disclose any use of AI tools, how they were used, and an estimate of how much of the final work involved them.

## Tool used

Claude, by Anthropic, used through Claude Code.

## How it was used

| Area | AI involvement |
|---|---|
| Problem research | Claude searched the web for fraud statistics, fraud methods and existing tools, and summarised them |
| Choice of idea | The direction was set by the team lead: real-time protection instead of practice, and the specific fraud situations to cover. Claude proposed how a phone could detect those moments |
| Code | The first draft of the Python engine, the Android app and the tests was written by Claude |
| Translations | The Marathi and Hindi text was drafted by Claude |
| Documents and presentation | First drafts were written by Claude |
